MULTIPLAYER REWORK (build this too)
--------------------------------------------------------------------------------
Rework the game from pass-the-phone hot-seat to Jackbox-style multiplayer:
- The COMPUTER is the host display by default: shows the lobby, the rankings,
  and the public game state for everyone in the room to watch.
- PLAYERS JOIN FROM THEIR PHONES via a short game code or by scanning a QR
  code shown on the host screen.
- On a player's phone: when it is YOUR TURN, the phone shows your actions; when
  it is NOT your turn, the phone shows your hand/resources plus a preview of
  what's publicly available (store, other players' public info).
- Host/player hybrid: the host screen has a "Join as player" button so the host
  can also enter the game as a player on their phone, with a toggle to switch
  the computer back to the host display whenever host actions are needed
  (dealing, advancing turns, etc.), then swap back.
- One game per code, stored as today (single game slot in the Sheet is fine to
  start); phones poll for state as the app already does.
